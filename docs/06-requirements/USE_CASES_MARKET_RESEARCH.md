## 1. 典型用户角色

### 1.1 调研经理 - 张总监

**背景**:
- 某工业设备制造企业市场部总监
- 负责新产品市场调研和竞品分析
- 管理 8 名外勤销售人员
- 年度调研预算 50 万元

**日常工作**:
- 制定市场调研计划
- 设计调研问卷
- 分配外勤任务
- 审批费用报销
- 分析市场数据
- 向高层汇报市场洞察

**痛点**:
- ❌ 传统问卷工具功能简单，无法满足复杂调研需求
- ❌ 外勤人员拜访记录不规范，数据质量差
- ❌ 费用报销流程繁琐，发票真假难辨
- ❌ 数据分析需要导出到 Excel 手工处理，效率低
- ❌ 无法实时了解外勤人员工作进度

**期待**:
- ✅ 一站式调研管理平台
- ✅ 实时掌握团队工作进度
- ✅ 自动化数据分析和报告生成
- ✅ 智能费用审批
- ✅ 专业的市场洞察工具

### 1.2 外勤销售 - 李经理

**背景**:
- 华东区域销售经理
- 负责 30+ 家客户的维护和开发
- 每月平均拜访客户 20 次
- 经常在外地出差

**日常工作**:
- 执行客户拜访任务
- 记录客户需求和反馈
- 收集市场信息
- 提交费用报销
- 协助客户填写调研问卷

**痛点**:
- ❌ 纸质拜访记录容易丢失
- ❌ 回公司后才能提交拜访报告，效率低
- ❌ 费用报销需要收集纸质发票，容易遗失
- ❌ 客户信息分散在笔记本、微信、Excel，难以查找
- ❌ 离线时无法访问客户资料

**期待**:
- ✅ 移动端随时记录拜访
- ✅ 离线也能工作
- ✅ 拍照即可提交费用
- ✅ 快速查找客户信息
- ✅ 语音录入节省时间

### 1.3 系统管理员 - 王总

**背景**:
- 集团 IT 部门负责人
- 管理 5 家子公司的系统账户
- 负责系统采购和预算控制

**日常工作**:
- 创建和管理公司账户
- 分配用户权限
- 监控系统使用情况
- 控制软件预算
- 确保数据安全

**痛点**:
- ❌ 多系统管理复杂
- ❌ 数据安全难以保障
- ❌ 无法统一监控各子公司使用情况
- ❌ 软件采购缺乏数据支持

**期待**:
- ✅ 统一的多公司管理平台
- ✅ 完善的权限控制
- ✅ 全面的审计日志
- ✅ 清晰的使用情况统计
- ✅ 灵活的定价方案

## 2. 市场调研场景

### 场景 2.1: 新产品市场调研

**背景故事**:
张总监所在公司计划推出一款新型工业机器人，需要了解目标市场的需求和竞争情况。

**业务流程**:

#### Step 1: 设计调研问卷（调研经理操作）

**操作路径**: 管理后台 → 问卷管理 → 创建新问卷

**功能需求**:
1. **问卷基本信息**
   - 问卷标题: "工业机器人市场需求调研"
   - 调研目标: 了解客户痛点、价格敏感度、竞品使用情况
   - 目标样本数: 100 份
   - 截止日期: 2025-12-31

2. **题型设计**（可视化拖拽）
   ```
   问题 1: 您公司目前是否使用工业机器人？
   - 类型: 单选题
   - 选项: 
     * A. 已使用 → 跳转到问题 3
     * B. 计划购买 → 跳转到问题 2
     * C. 暂无计划 → 跳转到问题 7
   
   问题 2: 您计划在何时购买？
   - 类型: 单选题
   - 选项: 3个月内 / 6个月内 / 1年内 / 不确定
   
   问题 3: 您目前使用的品牌是？
   - 类型: 多选题
   - 选项: ABB / KUKA / 发那科 / 其他（请注明）
   
   问题 4: 您对现有产品的满意度？
   - 类型: 量表题（1-5分）
   - 维度: 性能 / 价格 / 售后服务 / 易用性
   
   问题 5: 您最看重的功能是？
   - 类型: 排序题
   - 选项: 精度 / 速度 / 负载 / 稳定性 / 智能化
   
   问题 6: 您的预算范围？
   - 类型: 填空题
   - 验证: 数字类型，范围 10-1000 万元
   
   问题 7: 不购买的主要原因？
   - 类型: 开放题
   - 限制: 最少 20 字
   ```

3. **问卷设置**
   - ✅ 匿名/实名可选
   - ✅ 自动保存草稿
   - ✅ 设置必填项
   - ✅ 逻辑跳转规则
   - ✅ 移动端适配预览

4. **发布渠道**
   - 📧 邮件批量发送（从 CRM 导入客户列表）
   - 🔗 生成问卷链接（可嵌入官网）
   - 📱 生成二维码（展会现场扫码填写）
   - 👔 外勤协助填写（面对面访谈）

#### Step 2: 分配外勤任务（调研经理操作）

**操作路径**: 管理后台 → 任务管理 → 创建拜访任务

**功能需求**:
1. **任务创建**
   - 任务名称: "工业机器人市场调研-华东区"
   - 负责人: 李经理（外勤销售）
   - 目标客户: 30 家（从客户档案中筛选）
   - 截止日期: 2025-11-30
   - 任务目标: 每家至少完成 1 份问卷

2. **客户分配**
   ```
   智能分配建议（系统自动推荐）:
   - 基于地理位置优化路线
   - 考虑客户重要性（A/B/C级）
   - 避免任务冲突
   - 预估完成时间
   
   客户列表:
   √ 上海机械厂（A级，距离 5km）
   √ 江苏设备公司（B级，距离 15km）
   √ 浙江制造企业（A级，距离 80km）
   ...
   ```

3. **任务指令**
   - 📋 详细的拜访指导说明
   - 📱 问卷链接（支持离线填写）
   - 🗺️ 智能路线规划
   - ⏰ 推荐拜访时间
   - 📞 客户联系方式

#### Step 3: 执行拜访任务（外勤人员操作）

**操作设备**: Tauri 外勤客户端（Windows/Mac 桌面应用）

**场景描述**: 李经理到达上海机械厂，开始拜访

**功能需求**:

1. **到达签到**
   ```
   自动功能:
   - GPS 自动检测到达目标客户位置
   - 弹出签到提醒: "您已到达上海机械厂，是否开始拜访？"
   - 记录到达时间: 2025-10-28 09:30:15
   - 拍照记录: 自动调用相机拍摄门店照片（自动添加时间+GPS水印）
   ```

2. **拜访过程记录**
   ```
   录音功能:
   - 一键开始录音: 记录与客户的对话
   - 实时语音转文字（科大讯飞 API）
   - 自动识别关键信息（需求、价格、竞品等）
   
   照片记录:
   - 客户工厂车间现状
   - 现有设备型号和状态
   - 竞品产品照片
   - 客户名片
   ```

3. **协助填写问卷**
   ```
   面对面填写模式:
   - 加载问卷: "工业机器人市场需求调研"
   - 大字体显示（适合在客户面前展示）
   - 逐题引导客户回答
   - 支持中途暂停和继续
   - 自动保存进度（防止意外退出）
   ```

4. **拜访总结**
   ```
   结构化记录:
   客户反馈:
   □ 对现有产品满意度: 3/5 分
   □ 主要痛点: 维护成本高，故障率偏高
   □ 购买意向: 6个月内有采购计划
   □ 预算范围: 200-300 万元
   □ 竞品使用: 目前使用 ABB，考虑更换
   □ 决策人: 生产部经理王总
   
   商机评估:
   □ 成交概率: 70%
   □ 预计订单金额: 250 万元
   □ 预计成交时间: 2025-03-01
   □ 下次跟进计划: 1周后发送详细方案
   ```

5. **离开签退**
   ```
   自动功能:
   - 记录离开时间: 2025-10-28 11:45:30
   - 拜访时长统计: 2小时15分钟
   - 数据同步: 将所有记录上传到服务器
   - 更新任务状态: "上海机械厂"标记为已完成
   ```

#### Step 4: 数据收集和分析（系统自动 + 调研经理）

**实时数据汇总**:

1. **问卷回收统计**（系统实时更新）
   ```

   - 目标样本: 100 份
   - 已完成: 75 份 (75%)
   ```

2. **自动数据分析**（AI 驱动）
   ```

   ✓ 72% 的客户正在使用工业机器人
   ✓ ABB 品牌占有率最高（45%）
   ✓ 价格是第二重要考虑因素（仅次于性能）
   ✓ 华东地区客户预算普遍较高
   ✓ 售后服务满意度普遍偏低（平均 2.8/5.0）
   
   竞争分析:
   ✓ 主要竞品: ABB (45%), KUKA (25%), 发那科 (20%)
   ✓ 客户痛点: 维护成本高、故障率高、培训不足
   ✓ 价格敏感度: 中等（愿意为性能提升支付15%溢价）
   
   商机预测:
   ✓ 潜在客户: 28 家
   ✓ 预计总订单金额: 5,200 万元
   ✓ 平均成交周期: 4.5 个月
   ```
