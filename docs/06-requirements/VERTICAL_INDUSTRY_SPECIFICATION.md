# Flow Farm 垂直行业规格说明书

**项目定位**: 选项 B - 垂直行业工具  
**目标领域**: 市场调研与客户拜访管理  
**更新时间**: 2025年10月28日

---

## 1. 项目定位转变

### 1.1 从通用工具到垂直行业专家

#### 转变前（通用社交媒体自动化工具）
- ❌ 目标用户: 所有需要社交媒体获客的企业
- ❌ 核心功能: 多平台自动关注、通讯录管理、精准获客
- ❌ 竞争优势: 支持多平台（小红书、抖音、快手等）
- ❌ 市场壁垒: 低（易于被竞争对手复制）

#### 转变后（市场调研与客户拜访管理平台）
- ✅ 目标用户: B2B 企业的市场调研部门和销售团队
- ✅ 核心功能: 问卷设计、数据采集、客户拜访跟踪、费用管理
- ✅ 竞争优势: 深度行业定制、专业数据分析、合规性支持
- ✅ 市场壁垒: 高（行业know-how、数据积累、合规性要求）

### 1.2 业务场景对比

| 维度 | 社交媒体自动化 | 市场调研与客户拜访 |
|------|----------------|-------------------|
| **市场规模** | 大（所有企业） | 中（B2B企业） |
| **壁垒高度** | 低 | 高 |
| **客单价** | 中低（按关注数计费） | 高（企业级年费） |
| **续费率** | 中 | 高 |
| **风险** | 高（政策风险） | 低（合法合规） |
| **竞争强度** | 激烈 | 温和 |

## 2. 核心业务模块重新设计

### 2.1 市场调研管理模块

#### 2.1.1 问卷设计工具
**功能描述**: 提供可视化问卷设计器，支持多种题型和逻辑跳转

**核心特性**:
- 📝 题型支持: 单选、多选、填空、量表、矩阵题、排序题
- 🔀 逻辑跳转: 根据回答内容动态显示后续问题
- 🎨 模板库: 预置行业标准问卷模板（B2B、制造业、服务业等）
- 📱 多端适配: 自动适配 PC、平板、手机端展示
- 🌐 多语言: 支持中英文双语问卷

**技术实现**:
- 前端: React + Ant Design Form Builder
- 后端: Rust + SQLite (问卷结构 JSON 存储)
- 预览: 实时预览功能（WYSIWYG）

#### 2.1.2 数据采集引擎
**功能描述**: 多渠道数据采集和自动验证

**采集渠道**:
- 📧 邮件邀请: 批量发送问卷链接
- 📱 二维码: 生成问卷二维码用于现场采集
- 🔗 链接分享: 生成可追踪的分享链接
- 👔 外勤录入: 外勤人员现场协助填写

**数据验证**:
- 必填项检查
- 数据格式验证（邮箱、手机号、日期等）
- 逻辑一致性检查
- 重复提交检测

#### 2.1.3 数据分析与报告
**功能描述**: 智能数据分析和可视化报表生成

**分析维度**:
- 📊 描述统计: 频数、百分比、均值、中位数
- 📈 趋势分析: 时间序列分析、同比环比
- 🔍 交叉分析: 多维度交叉表分析
- 🎯 相关性分析: 变量间相关性计算
- 🗺️ 地域分布: 地图热力图展示

**报告生成**:
- PDF 导出（专业格式）
- Excel 数据导出
- PowerPoint 图表导出
- 在线分享（可控权限）

### 2.2 客户拜访管理模块

#### 2.2.1 拜访计划管理
**功能描述**: 智能拜访计划制定和任务分配

**核心功能**:
- 📅 日程管理: 可视化日历视图
- 🗺️ 路线规划: 基于地理位置的最优路线推荐
- 👥 客户分级: A/B/C 级客户分类管理
- ⏰ 提醒通知: 拜访前提醒（推送/短信/邮件）
- 📋 任务分配: 调研经理分配拜访任务给外勤人员

**智能推荐**:
- 根据客户价值优先级排序
- 考虑地理位置优化路线
- 避免拜访冲突（时间和人员）

#### 2.2.2 拜访记录系统
**功能描述**: 全方位拜访过程记录和跟踪

**记录内容**:
- 📸 **现场照片**: 客户门店/办公室照片（自动添加水印：时间+GPS）
- 🎤 **语音记录**: 语音转文字（AI 自动整理要点）
- 📍 **GPS 定位**: 自动记录拜访地点（防作弊）
- ⏱️ **时长统计**: 拜访开始/结束时间自动记录
- 📝 **拜访总结**: 结构化拜访报告（客户反馈、需求、竞品信息等）
- 📎 **附件上传**: 合同、名片、产品资料等

**数据验证**:
- GPS 定位偏差检测（与客户地址比对）
- 拜访时长合理性检查
- 必填项强制填写
- 照片真实性检测（时间戳、地理位置水印）

#### 2.2.3 客户关系管理 (CRM Lite)
**功能描述**: 轻量级客户关系管理

**客户档案**:
- 基本信息（公司名称、联系人、电话、地址）
- 行业分类和规模
- 拜访历史记录
- 商机跟踪
- 合作状态（潜在客户、意向客户、成交客户、流失客户）

**商机管理**:
- 商机阶段跟踪（接触、需求确认、方案提交、谈判、成交）
- 预计成交金额和时间
- 成交概率评估
- 跟进提醒

### 2.3 费用管理模块

#### 2.3.1 费用报销流程
**功能描述**: 外勤人员费用报销和审批

**报销类型**:
- 🚗 交通费: 公交、地铁、出租车、高铁、飞机
- 🍽️ 餐饮费: 客户招待、工作餐
- 🏨 住宿费: 酒店住宿
- 📞 通讯费: 电话费、流量费
- 🎁 业务招待: 礼品、样品
- 📄 其他费用: 打印、快递等

**报销流程**:
1. 外勤人员提交报销申请（附发票照片）
2. 系统自动检测发票真伪（OCR + 税务验证）
3. 调研经理审批
4. 财务确认打款
5. 状态实时通知

**智能审批**:
- 费用标准检查（超标提醒）
- 重复报销检测
- 发票真伪验证
- 预算余额检查

#### 2.3.2 预算管理
**功能描述**: 部门/项目预算控制

**预算维度**:
- 按部门分配预算
- 按项目分配预算
- 按人员分配预算
- 按费用类型分配预算

**预算控制**:
- 实时预算使用情况
- 预算预警（80%、90%、100%）
- 超预算审批流程
- 预算调整申请

## 3. 三角色权限架构

### 3.1 系统管理员（Super Admin）
**职责**: 平台整体管理和公司管理

**权限**:
- ✅ 公司账户管理（创建、删除、冻结）
- ✅ 定价策略设置（按用户数、按功能模块）
- ✅ 系统配置管理
- ✅ 全局数据统计
- ✅ 审计日志查看
- ❌ 不能查看具体调研数据（数据隔离）

### 3.2 调研经理（Research Manager）
**职责**: 调研项目和团队管理

**权限**:
- ✅ 问卷设计与发布
- ✅ 调研项目管理
- ✅ 外勤人员管理（创建、分配任务、考核）
- ✅ 拜访任务分配和审批
- ✅ 费用审批
- ✅ 数据分析和报告生成
- ✅ 客户档案管理
- ❌ 不能修改公司级别设置

### 3.3 外勤人员（Field Worker）
**职责**: 执行拜访任务和数据采集

**权限**:
- ✅ 查看分配给自己的任务
- ✅ 记录拜访过程（照片、语音、定位、总结）
- ✅ 提交费用报销
- ✅ 查看个人 KPI
- ✅ 客户档案查询（只读）
- ✅ 协助客户填写问卷
- ❌ 不能查看其他人员的数据
- ❌ 不能修改已完成的拜访记录

## 4. 技术架构适配

### 4.1 后端服务 (Rust + Axum)

#### 新增 API 模块
```
src/handlers/
├── surveys.rs           # 问卷管理 API
├── visits.rs            # 拜访管理 API
├── expenses.rs          # 费用管理 API
├── customers.rs         # 客户管理 API
├── analytics.rs         # 数据分析 API
├── kpi.rs               # KPI 统计 API (保留)
└── reports.rs           # 报告生成 API (保留)
```

#### 数据模型设计
```sql
-- 问卷表
CREATE TABLE surveys (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT,
    structure JSON NOT NULL,  -- 问卷结构
    status TEXT NOT NULL,     -- draft/published/closed
    created_by INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 问卷响应表
CREATE TABLE survey_responses (
    id INTEGER PRIMARY KEY,
    survey_id INTEGER NOT NULL,
    respondent_info JSON,
    answers JSON NOT NULL,
    submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    ip_address TEXT,
    user_agent TEXT
);

-- 客户表
CREATE TABLE customers (
    id INTEGER PRIMARY KEY,
    company_name TEXT NOT NULL,
    industry TEXT,
    contact_person TEXT,
    contact_phone TEXT,
    contact_email TEXT,
    address TEXT,
    city TEXT,
    province TEXT,
    latitude REAL,
    longitude REAL,
    level TEXT,  -- A/B/C级客户
    status TEXT, -- potential/interested/deal/lost
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 拜访记录表
CREATE TABLE visits (
    id INTEGER PRIMARY KEY,
    customer_id INTEGER NOT NULL,
    employee_id INTEGER NOT NULL,
    planned_date DATE,
    actual_start_time TIMESTAMP,
    actual_end_time TIMESTAMP,
    location_latitude REAL,
    location_longitude REAL,
    photos JSON,  -- 照片URLs数组
    audio_record TEXT, -- 语音文件URL
    summary TEXT,
    feedback JSON,
    status TEXT,  -- planned/completed/cancelled
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 费用报销表
CREATE TABLE expense_claims (
    id INTEGER PRIMARY KEY,
    employee_id INTEGER NOT NULL,
    visit_id INTEGER,
    expense_type TEXT NOT NULL,
    amount DECIMAL(10,2) NOT NULL,
    invoice_photo TEXT,
    description TEXT,
    status TEXT,  -- pending/approved/rejected/paid
    submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    approved_at TIMESTAMP,
    approved_by INTEGER
);
```

## 5. 竞争优势和壁垒

### 5.1 行业壁垒
- **专业性**: 深度理解市场调研和B2B销售流程
- **合规性**: 符合数据保护法规（GDPR、个人信息保护法）
- **数据积累**: 行业数据库和标准问卷模板
- **know-how**: 数据分析算法和市场洞察模型

### 5.2 技术壁垒
- **AI 智能分析**: 自然语言处理（NLP）分析开放式问题
- **图像识别**: 发票真伪检测、GPS 水印验证
- **路线优化算法**: 基于地理位置的智能路线规划
- **离线同步机制**: 复杂的离线数据同步和冲突解决

### 5.3 差异化优势
| 维度 | 通用 CRM/调研工具 | Flow Farm |
|------|-------------------|-----------|
| **行业聚焦** | 通用 | B2B市场调研专家 |
| **移动端体验** | 一般 | 优秀（Tauri原生） |
| **离线支持** | 无或弱 | 完整离线能力 |
| **数据分析** | 基础统计 | 深度市场洞察 |
| **合规性** | 一般 | 高（数据隔离、审计） |
| **客单价** | 中低 | 高（企业级） |
